Foundations

Color

One dark theme: blue-black surfaces that step lighter with elevation, a single cyan accent, and a reserved status vocabulary. Every ink token holds ≥4.5:1 contrast on every surface it may sit on; the chart palette passed the six-check categorical validator against surface-1.

Surfaces#

Four layers. Elevation lightens the surface and adds a hairline — shadows are reserved for detached layers (Elevation & shape). Inputs sit on void so filled fields read as wells, not cards.

Accent — Earthlight#

One accent. Cyan-blue marks interaction and selection: buttons, links, focus, selected rows, active tabs. It is deliberately distinct from every status hue so a selected row never reads as "healthy" and an alarm never reads as "clickable".

Status & limit semantics#

Reserved vocabulary (OMCT-C06-L2-04.03 limit evaluation, C14 notification severities, C04 connection states). Filled variants always take ink-inverse text; a status color is never the only signal — pair with glyph or label (OMCT-C16-L2-03.01).

Chart palette (chart.js)#

Eight categorical slots in a fixed order chosen to maximize color-vision-deficiency separation. Assign in sequence, never cycle, never re-color survivors when series are removed; a ninth series folds into "Other". Series identity is always backed by the legend and direct labels — the palette sits in the CVD floor band, so labels are mandatory, not decorative.

Angular mapping#

Angular Tokens feed a custom Material 17 dark theme; publish them on :root and reference from component SCSS. 
// styles/_theme.scss
@use '@angular/material' as mat;

$cupola-primary: mat.define-palette((
  50: #E7F5FD, 100: #C9E9FB, /* … */ 500: #58B7EC,
  contrast: (500: #0B0E14)
), 500);

$cupola-theme: mat.define-dark-theme((
  color: (primary: $cupola-primary, accent: $cupola-primary, warn: mat.define-palette($warn-palette)),
  typography: $cupola-typography,  // see Typography
  density: -2,
));
