Spacing & density

A 4px base unit and Material density −2. Operators scan walls of data, so space lives between regions (panes, sections, dialogs), not inside controls. Telemetry rows compress to 24px; chrome rows hold 32px.

The layout grid#

Display layouts snap items to a 10px grid (OMCT-C09-L2-01.03). The grid is only visible in edit mode; it renders as a 6%-alpha line lattice over the void canvas. Gridster panels on dashboards use the same unit for margins (10px gutters).
