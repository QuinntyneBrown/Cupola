Motion

Motion in a control room answers one question: what just changed? Three durations, two easings, no bounce, no parallax, no page transitions. Anything decorative competes with telemetry for attention and loses its place here.

Tokens#

TokenValueUse
--cp-motion-fast80msHover fills, ink changes, border color
--cp-motion-base140msMenus, tooltips, chevron rotation, switch travel
--cp-motion-slow240msDialog entry, pane collapse, progress fill
--cp-ease-standardcubic-bezier(0.2, 0, 0, 1)Everything entering or changing
--cp-ease-exitcubic-bezier(0.3, 0, 1, 1)Things leaving (menus closing, toasts dismissing)

Where motion is allowed#

SurfaceAnimationSpec
Menus / tooltipsFade + 4px rise, 140msenter only; exit is 80ms fade
DialogsFade + scale 0.98→1, 240ms; scrim fades in parallelOMCT-C15-L2-04.04
Expansion panels / treeChevron rotates 90°, 140ms; content clips, no slide
Progress / spinnersContinuous; the only infinite animations in the systemOMCT-C14-L2-04.03
Live valuesNo animation. Values swap instantly; tabular figures prevent jitterOMCT-C06
Remote-change flashRow background pulses primary-dim once, 240msOMCT-C04-L2-02.05
Plots (chart.js)animation: false — frames must track the conductor, not tweenOMCT-C07
Live examples — hover fill, switch travel, indeterminate progress, spinner.

Reduced motion#

prefers-reduced-motion: reduce zeroes all three duration tokens, so every transition collapses to an instant state change. Spinners and indeterminate bars slow to a crawl instead of stopping — in-progress feedback is still information (OMCT-C16-L2-03.01). 

@media (prefers-reduced-motion: reduce) {
  :root { --cp-motion-fast: 0ms; --cp-motion-base: 0ms; --cp-motion-slow: 0ms; }
  .cp-spinner { animation-duration: 2.4s; }
}

Angular mapping#

Angular Prefer CSS transitions over Angular animations. Where Material animates internally, keep defaults but honor provideAnimationsAsync('noop') when the OS requests reduced motion. Set animation:false in every chart.js config.
