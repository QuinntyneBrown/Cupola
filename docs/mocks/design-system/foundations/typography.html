Typography

One superfamily, three cuts. IBM Plex Sans carries the interface, IBM Plex Mono carries every number the spacecraft produces, and IBM Plex Sans Condensed labels panels the way placards label switches. Roboto is deliberately replaced in the Material typography config.

Type scale#

Each level is a single font shorthand token. Base UI size is 14px; the scale is compact because the working surfaces are dense.

Usage rules#

  • If a human didn't write it, set it in mono. Values, timestamps, identifiers, units, coordinates. Names and descriptions stay in sans.
  • Tabular figures in columns. Any vertically aligned numbers (tables, ticks, conductor) get tabular-nums so updates don't jitter.
  • Units are muted, values are not. The unit renders in ink-3 one step smaller, separated by a thin space.
  • Condensed caps never exceed 12px and never set running text — headers and eyebrows only.
  • Stale values go italic in the same mono face, with the history glyph (Color › status).
  • Weights: 400 body, 500 labels/mono emphasis, 600 headings. Nothing bolder; hierarchy comes from size, color, and case.
Do
101.32 kPa
Mono value, muted smaller unit.
Don't
101.32 KPA
Proportional bold figures jitter as they update; the unit shouts.

Angular mapping#

// styles/_typography.scss — replaces Roboto across Material
$cupola-typography: mat.define-typography-config(
  $font-family: 'IBM Plex Sans',
  $headline-4: mat.define-typography-level(28px, 34px, 600),
  $headline-6: mat.define-typography-level(20px, 28px, 600),
  $subtitle-1: mat.define-typography-level(16px, 24px, 600),
  $body-1:     mat.define-typography-level(14px, 20px, 400),
  $body-2:     mat.define-typography-level(12px, 16px, 400),
  $button:     mat.define-typography-level(13px, 16px, 500),
  $caption:    mat.define-typography-level(11px, 14px, 400),
);
