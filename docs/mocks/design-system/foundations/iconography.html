Iconography

A single stroke set: 24px grid, 1.75px stroke, round caps and joins, no fills except dot glyphs. Object-type glyphs identify every node in the tree (OMCT-C02-L2-01.02); action and status icons share the same construction so nothing looks imported.

Object-type glyphs#

One glyph per creatable type. The glyph appears in the tree, the Create menu, search results, breadcrumbs, and view headers — always the same shape.

Usage rules#

  • Icon-only controls carry an accessible name (aria-label) and a tooltip. No unlabeled mysteries in an ops console.
  • Status glyphs never travel alone — pair with a label or value (OMCT-C16-L2-03.01, no color-only signaling).
  • Decorations stack right of the glyph: alias (link), lock, and missing badges render at 12px after the type glyph in tree rows.
  • Never restyle stroke weight per icon. Emphasis comes from ink color, not thickness.

Angular mapping#

Angular Register the sprite with MatIconRegistry.addSvgIconSet() and render via <mat-icon svgIcon="folder">. The sprite ships as a build asset; ids match the names above.
