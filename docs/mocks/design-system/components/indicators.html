Indicators & chips

The indicator bar is the operator's peripheral vision — a 28px strip at the bottom of the shell where every plugin reports health without stealing focus. One rule governs everything on this page: status color never travels alone. Every state pairs its color with an icon or a label.

The indicator bar#

A single horizontal strip, .cp-statusbar, 28px tall on the void surface. Plugins contribute indicators; the shell sorts them by declared priority, highest first (leftmost), so the bar reads the same on every screen.

User & role#

When a user provider is installed the indicator shows the user icon, the login name, and the active role. Clicking opens the role selector; choosing a role broadcasts to everything role-aware (poll visibility, annotation attribution). Without a provider, no name is shown — the indicator does not render at all.

Operator status & poll#

Operator status is a filled chip — the only filled status element in the bar, because it is the one the whole room reads at a glance. Four states:

GO NO-GO STANDBY NOT SET
Filled status chips take dark ink; NOT SET stays a plain chip — an unanswered poll is not an alarm.

Clicking the chip opens the status poll widget. The poll question is set by an authorized role; everyone else sees it read-only. Responses roll up anonymously by status.

Clear Data#

An action indicator, not a status: clicking clears buffered telemetry from every open view without a page reload. Because it destroys the operator's working context, it always confirms first — a dialog naming what will be cleared, with the danger button carrying the verb.

Confirmation required. "Clear all telemetry from open views? New data continues to stream." — Cancel · Clear Data (danger).
The indicator and its confirmation contract — data clears only after explicit confirm.

Chips & tags#

Chips label and filter; they never alarm (status chips above are the only filled ones). Tag chips carry a dot colored by the tag's configuration — colors come from the chart palette slots, so tags stay inside the validated palette.
