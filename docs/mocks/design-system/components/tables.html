Tables

The telemetry table is the ops workhorse: one datum per row, mono numerals, 24px row height, limit and staleness semantics carried in every cell. The same anatomy scales down to latest-available-data (LAD) tables and the ultra-dense autoflow view.

Telemetry table anatomy#

A telemetry table renders each datum as a row — Timestamp (mono, in the active time system), Value, and Unit — newest first in real-time mode (OMCT-C08-L2-01.01). The header is sticky; a per-column filter row sits directly beneath it. The view toolbar carries pause, mark-row, export, and column-configuration controls.

Row & cell states#

Every state has to survive a wall of numerals: selection and marking fill with primary cyan, limit violations fill the value cell (never the whole row) with the status color plus a direction arrow, and stale rows drop to italic muted ink with a history glyph — never color alone.

In-place updates: rows are keyed by datum identity (source key + timestamp). When a datum is re-emitted — a late sample, a corrected value — the existing row is replaced in place; the table never removes and re-appends, so nothing flickers or loses selection (OMCT-C08-L2-01.03).

Paused, loading & empty#

Marking a row (or pressing pause) freezes real-time row motion so the operator's reference point doesn't scroll away (OMCT-C08-L2-01.06). Paused is a mode, not an alarm — the badge is outlined and neutral, like the edit badge, never status-colored. The table resumes automatically when the conductor bounds change (OMCT-C08-L2-01.07).

Column configuration#

The gear opens a column panel: checkboxes toggle visibility, grips reorder by drag, and Auto-size lets the table fit column widths to content. Configuration persists with the view (OMCT-C08-L2-01.04).

Columns
Checkbox = visibility · grip = drag to reorder · Auto-size fits widths to content (currently on). Turning it off preserves manually dragged widths with the view.
Angular CDK overlay panel; row order via cdkDropList. Column state serializes into the view's configuration object.

Export#

The export control offers the full result set or just the marked rows; the marked option is disabled until at least one row is marked (OMCT-C08-L2-01.08).

Export
No rows are marked, so the marked-rows export is disabled — disabled, not hidden, so the capability stays discoverable.

CSV hardening: any cell whose text begins with =, +, -, or @ is prefixed with a single quote on export so spreadsheet applications treat it as text, never as a formula (OMCT-C16-L2-04.03).

LAD tables — latest available data#

A LAD table shows exactly one row per telemetry object — its latest datum within the conductor bounds: Name, Timestamp, Value with unit (OMCT-C08-L2-02.01). Rows update in place as new data arrives (OMCT-C08-L2-02.02); limit and stale styling are identical to the full table.

Autoflow tabular view#

Autoflow packs name+value pairs into 24px rows that fill a column top-to-bottom, then flow into the next column (OMCT-C08-L2-04.01/04.02). It is the densest telemetry surface in the system — values update in place (OMCT-C08-L2-04.03) and carry the same limit and stale semantics as full tables (OMCT-C08-L2-04.04).
