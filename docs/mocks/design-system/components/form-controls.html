Form controls

The form API registers eleven default control types (OMCT-C15-L2-04.01): text, textarea, number, select, autocomplete, datetime, checkbox, toggle switch, file input, locator, and composite. Type-driven Create and Edit Properties dialogs assemble forms from these controls (OMCT-C03-L2-01.01), so each one is specified with every state here.

Field anatomy & states#

Every control sits in the same wrapper: label above (4px gap), control, helper line below (4px gap, 14px reserved). Inputs sit on the void surface so they read as wells.

Datetime#

Conductor bounds, plan windows, and export ranges share one control: a mono text input in the active time-system format with a calendar trigger. Invalid ranges (end ≤ start) reject with an error, never silently clamp (OMCT-C05-L2-04.01).

Locator — the "Save In" tree picker#

Create, Duplicate, Move, Link, and Import all end with the same question: where? The locator embeds the object tree; parents that reject the type by composition policy are disabled, not hidden, so the operator sees why a target is unavailable (OMCT-C02-L2-03.04).
