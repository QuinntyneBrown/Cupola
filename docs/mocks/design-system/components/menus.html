Menus

Every menu — context menu, view actions, the Create super menu — is the same level-3 surface with 32px items. Menus never invent actions: the action registry returns what applies to the selection (OMCT-C15-L2-03.01), items that don't currently apply are disabled with a reason, and items that never apply are absent (OMCT-C15-L2-03.02).

Create super menu#

The Create button in the tree pane opens the one super menu in the product: every registered creatable type with its glyph, and a description pane that follows hover and arrow-key focus (OMCT-C15-L2-03.04). Choosing a type opens the type-driven Create dialog (OMCT-C03-L2-01.01).

Press Enter to open the Create dialog.

Hover or arrow-key an item — the pane shows the 32px type glyph, name, and description. The list comes from the type registry; plugins add rows without touching the menu.
Angular .cp-supermenu is a single CDK Overlay panel: a mat-menu-styled list plus a description pane bound to the focused item. Types stream from the type registry (OMCT-C02-L2-01.02).

Placement#

A menu opens at the requested screen coordinate — usually the pointer — growing down-right (OMCT-C15-L2-03.03). When the preferred placement would leave the viewport, the menu flips on that axis so it stays fully visible; it never scrolls the page and never covers the invoking point (OMCT-C15-L2-03.04).

Left: default placement grows down-right from the invocation point. Right: near the viewport edge the same menu flips up-left. Crosshairs mark the requested coordinates.
