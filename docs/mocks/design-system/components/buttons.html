Buttons

Five emphasis levels, one height (32px), one radius (3px). A view region gets at most one filled button — the action the operator came to perform. Everything else steps down.

Icon buttons#

Default · active/pressed · disabled · small (28px). Every icon button has aria-label + tooltip.

Toggle groups#

Mutually exclusive view options: conductor mode, grid/list switch, legend collapse. Exactly one segment is pressed.

Interactive — click a segment. Material: mat-button-toggle-group.

Placement rules#

  • Dialogs: actions right-aligned in the footer, affirmative last: Cancel · Save. Destructive confirms use danger-filled: Cancel · Remove.
  • Toolbars: icon buttons and small text buttons only; the filled button lives in content or dialog footers, not toolbars (exception: the tree pane's Create).
  • Verbs, not ceremonies: buttons say what happens — "Save", "Remove", "Import" — never "Submit", "Yes", or "Proceed".
