Drag & drop#

Dropping adds to or reorders the target's model-backed composition (OMCT-C02-L2-03.02) — but only after every registered composition policy accepts the pairing. A folder takes a plot; a telemetry point takes nothing, and the row says so before the drop (OMCT-C02-L2-03.04).

The ghost follows the pointer at drag z-index. "Power dashboards" accepts the plot (cyan inset ring); "Bus voltage" rejects it (critical ring, no-drop cursor) because a telemetry point's composition takes no children.
Angular cdkDragDrop with a custom drag preview for the ghost; cdkDropList enter predicates call the composition policy service, so invalid targets reject during the drag, not after the drop.

Search#

The search field above the tree queries every object provider in parallel (OMCT-C02-L2-04.01) and streams results in as each provider answers — a slow archive never blocks the in-memory index. The same interface returns objects and notebook annotations (OMCT-C15-L2-05.05); partial matching comes from the shared-worker index, with an in-process fallback where workers are unavailable (OMCT-C02-L2-04.02/.03).
