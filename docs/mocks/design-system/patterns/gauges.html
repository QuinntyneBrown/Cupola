Gauges & widgets

Fixed-position readouts for values that matter at a glance: five gauge forms (OMCT-C08), plus the condition-driven widgets of OMCT-C10 — condition widget, summary widget, and the condition set editor that powers them. Dials are inline SVG; meters are DOM. Gauge fills use the accent primary; caution and critical are reserved for limit semantics, never decoration.

The five gauge forms#

Every gauge type renders the same data contract — current value, unit, min/max, optional caution/critical bands — in one of five mandated forms (OMCT-C08-L2-03.01). The value is always large mono ink; the unit is muted; limit bands wear status colors at the high (or low) end of the scale.

Gauge states#

When the value enters a limit band the fill itself changes to the violated severity, paired with a direction glyph and a label — never color alone (OMCT-C08-L2-03.03, OMCT-C06-L2-04.03). Stale telemetry renders the value italic in stale ink with the history glyph (OMCT-C06-L2-04.04).

Where limits come from#

A gauge's scale and bands are configured one of two ways (OMCT-C08-L2-03.02) — the rendering is identical either way, so the operator never needs to know which is in effect.

SourceBehavior
Manual boundsMin, max, and caution/critical thresholds entered in the gauge's properties form. Used when telemetry metadata carries no range definitions.
Telemetry-derivedMin/max and limit bands read from the telemetry point's metadata limit definitions; the gauge re-scales automatically when the dictionary updates.

Condition widget#

A condition widget is a stylable box showing the label of its condition set's active output (OMCT-C10-L2-02.02). Background, border, and text restyle per output via conditional styles. When a URL is configured the widget becomes a click target, marked with the external-link glyph.

Summary widget & rules editor#

A summary widget rolls several telemetry points into one icon + label + color, driven by an ordered rule list (OMCT-C10-L2-02.03). Each rule picks an icon, a color from the status vocabulary, and a scope — whether a single point, any, or all of them must match (OMCT-C10-L2-02.04). Rules evaluate top-down; the first match wins.

Condition set editor#

A condition set evaluates an ordered list of conditions against telemetry and emits the output of the first condition that is true (OMCT-C10-L2-01.01/01.02). Each condition triggers when ANY or ALL of its criteria match (01.03) and names the output value it produces (01.04). An old-data criterion fires when telemetry exceeds an age interval (01.05); the default condition at the bottom catches everything else (01.06).

Conditional styles panel#

Any stylable object bound to a condition set gets a style row per output: background, border, and text color, edited in the inspector (OMCT-C10-L2-02.01). The master switch disables all conditional styling without discarding the rows.
