Patterns

Time conductor

One bar governs what every telemetry view shows: the active time system, the visible bounds, and the mode — fixed bounds or bounds that follow a clock. The conductor shows the controls for whichever mode is active (OMCT-C05-L2-04.01) and mirrors its state into the URL so a shared link reproduces the same window (OMCT-C05-L2-04.03).

Fixed mode#

Fixed mode means no active clock (OMCT-C05-L2-03.01): the operator states a start and an end, then submits. The time-system select lists only registered systems (OMCT-C05-L2-01.01/.02); each carries its own format — UTC and Duration (OMCT-C05-L2-05.01), Local and ISO (OMCT-C05-L2-05.02). The gray top edge is the fixed-mode signal.

→ span 12:00:00
Fixed-mode conductor: mode toggle, time system, start → end in the active format (mono), submit. Bounds apply on submit or Enter — never while typing.
Angular mat-button-toggle-group for the mode, mat-select for time system and clock, custom datetime control (see Form controls). A TimeService exposes signals for system, bounds, mode, and clock, mirroring the TimeAPI event set (OMCT-C05-L2-01.05).

Real-time mode#

Real-time mode means a registered clock is active (OMCT-C05-L2-03.01/.02). Bounds derive from each tick plus the configured offsets (OMCT-C05-L2-03.03), and the conductor shows the current clock value, updating on every tick (OMCT-C05-L2-04.02). Three clocks ship: local wall clock (OMCT-C05-L2-03.04), remote telemetry clock (OMCT-C05-L2-03.05), and the latest-available-data clock (OMCT-C05-L2-03.06). The green top edge and green mono clock are the live signals.

Real-time UTC → 2026-07-13 18:22:04.000 →
Real-time conductor: clock select, start offset −00:30:00, live clock value (green mono, ticks every second), end offset +00:00:30. Offsets are buttons — clicking opens the duration editor.

Bounds validation#

A range where end ≤ start is rejected, never clamped (OMCT-C05-L2-01.03). The invalid field takes the error treatment, an error line explains, and the previously applied bounds stay in effect until a valid range is submitted (OMCT-C05-L2-04.01).

→
End must be after start — bounds not applied; the previous range 17:52:04 → 18:22:04 remains in effect.
Rejected range: the end field errors, submit disables, and views keep rendering the last valid bounds (OMCT-C05-L2-01.03, 04.01).

Date/time picker#

The calendar buttons open a level-3 popup: month grid with mono day numbers, plus hour/minute/second fields. Today wears an outline; the selected day fills primary. Days outside the month are dimmed but clickable.

Independent time conductor#

Views use the global time context unless an object in their path owns an independent one (OMCT-C05-L2-02.01/.02). A view running on its own time gets the out-of-sync treatment: a primary-border outline around the whole frame, a clock badge in its header, and a per-view conductor strip. Descendants without their own context follow the nearest ancestor's independent context (OMCT-C05-L2-02.03) — a plot inside this frame ticks with the frame, not with the global conductor.

Angular Hierarchical DI mirrors the context tree: a frame with independent time provides its own TimeContext; descendants inject the nearest provider, so ancestor inheritance (OMCT-C05-L2-02.03) is the injector walk.

Time of interest#

Clicking a plot or table row sets the time of interest: a vertical crosshair with a mono timestamp flag, synchronized across every view on the same context. New bounds that exclude the marked time clear it (OMCT-C05-L2-01.04).

2026-07-13 18:12:31.250
Time-of-interest crosshair with mono timestamp flag. Panning or re-bounding past it clears the marker (OMCT-C05-L2-01.04); no orphaned flags.

Clock & Timer objects#

Clocks and timers are also domain objects with views. A Clock displays per its configuration — timezone, 12/24-hour, format (OMCT-C05-L2-05.03). A Timer counts up or down from a target through started, paused, and stopped states (OMCT-C05-L2-05.04); legacy timer properties migrate on load (OMCT-C05-L2-05.05).

Timer values are large mono with an explicit sign — count-up shows +, countdown to target shows −. Start/Pause/Restart are icon actions; Stop is a labeled text button (no square glyph in the icon set — the word is clearer).

URL reflection#

Global mode, time system, and bounds or offsets synchronize with URL search parameters (OMCT-C05-L2-04.03). Reloading or sharing the link reproduces the exact time window; independent per-view contexts are persisted with their object, not in the URL.

// Fixed: absolute bounds travel in the URL
#/browse/mine/station-displays/solar-array-output
    ?tc.mode=fixed&tc.timeSystem=utc
    &tc.startBound=1783879200000&tc.endBound=1783922400000

// Real-time: the clock key and offsets travel, not bounds
#/browse/mine/station-displays/solar-array-output
    ?tc.mode=local&tc.timeSystem=utc
    &tc.startDelta=1800000&tc.endDelta=30000
