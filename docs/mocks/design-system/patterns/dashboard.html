Patterns

Layouts & dashboards

Display layouts compose child objects and drawing elements on a fixed 10px-snap canvas (OMCT-C09-L2-01.01); flexible layouts split space into proportional containers and panes. Both browse clean and edit violet — edit-mode affordances never borrow status colors.

Display layout — browse mode#

In browse mode the canvas is just the composed view: each sub-object frame embeds that object's default view, live against the current time bounds (OMCT-C09-L2-01.04). No grid, no handles, no outlines beyond each frame's own chrome.

Display layout — edit mode#

Entering edit mode reveals the 10px snap lattice and the edit toolbar. Selection outlines, handles, and the rotation affordance are violet (--cp-color-edit) — edit is a mode, not an alarm. Position, size, rotation, and stacking order persist with the layout (OMCT-C09-L2-01.03); selected items copy and paste with their geometry (OMCT-C09-L2-01.05).

Composition stays in sync#

One source of truth. Dropping a child into the layout's composition auto-creates a sub-object frame at the drop point; removing the child removes its layout item — geometry never outlives membership (OMCT-C09-L2-01.02).
  • Drag from the tree onto the canvas → child is added to composition and a frame appears at the pointer, snapped to the grid.
  • "Remove" on a frame → removes the child from composition; the layout item and its geometry are deleted together.
  • Drawing elements (text, image, box, line) are layout-only items — they never appear in composition.

Flexible layout#

A flexible layout divides its area into containers, each holding proportional panes (OMCT-C09-L2-02.01). Splitters between panes and containers resize by drag (OMCT-C09-L2-02.02); the toolbar toggles the whole layout between rows and columns (OMCT-C09-L2-02.03). Container outlines and labels are violet — they exist only in edit mode.

Dashboard grid — angular-gridster2 mapping#

Free-form dashboards (multi-widget home screens) use angular-gridster2 with a fixed cell size tied to the same 10px layout grid, so display layouts and dashboards share one visual rhythm. Drag and resize are only enabled while editing.

Angular GridsterConfig below is the canonical dashboard config; margin and cell size both read --cp-layout-grid. 
// dashboard.component.ts — canonical gridster options
const options: GridsterConfig = {
  gridType: 'fixed',
  fixedRowHeight: 10,          // --cp-layout-grid
  fixedColWidth:  10,          // --cp-layout-grid
  margin: 10,                  // gutters on the same unit
  outerMargin: false,
  draggable:  { enabled: this.isEditing },   // browse mode is inert
  resizable:  { enabled: this.isEditing },
  compactType: 'none',        // operator geometry is never "helpfully" moved
  pushItems: false,
  displayGrid: 'onDrag&Resize' // lattice appears only while manipulating
};

Hyperlink object#

A hyperlink object stores a URL and a display style (OMCT-C09-L2-04.01). It presents as an inline link or as a button, and can target the same tab or a new one (OMCT-C09-L2-04.02) — new-tab links always show the external glyph.
