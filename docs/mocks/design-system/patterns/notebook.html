Patterns

Notebook

Notebooks are the mission log: sections contain pages, pages contain timestamped entries with sanitized rich text, embedded snapshots, and tags. Restricted notebooks add committed (locked) entries and a URL whitelist. Annotations attach the same tag vocabulary to points, regions, and objects anywhere in the workspace.

Notebook layout#

Three columns: sections, pages, entries. Sections and pages support inline add / rename / delete; the pin marks the default entry destination — “new entry” actions anywhere in Cupola land on the pinned notebook + section + page.

Entry anatomy & states#

An entry is a mono timestamp, an optional author, sanitized rich-text body, embedded snapshots, and tag chips. Markdown renders through the sanitizer — script, style, and event-handler content is stripped before display. In a restricted notebook, committed entries lock permanently and only whitelisted URLs render as links.

Live synchronization#

Notebooks are shared documents: entries added, edited, or deleted by other operators appear, update, or disappear in place — no reload, no “refresh” action. Remote changes never steal focus from an entry being written locally.

Synced live. e.thorne added an entry to EVA operations · “EVA 71 — P6 battery swap” 12 s ago; it appeared in place without a reload.

Annotations & tags#

Annotations attach tags and comments to targets anywhere — plot points, image regions, map features, or whole objects. Tag colors come from the chart palette slots, shared with notebook entry tags. Creation fails loudly when the target lives in a read-only namespace.

Target summary (what is annotated + mono time range), removable tag chips, and a tag combobox — suggestions appear only once a term is typed. Rejected creation keeps the selection and explains why.
Angular Tag picker is mat-autocomplete over the shared tag vocabulary; annotations load with the target’s view and render as chips/markers in place. Writes go through the annotation provider — read-only namespaces reject with the banner above.
