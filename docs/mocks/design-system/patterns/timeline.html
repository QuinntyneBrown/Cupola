Plans & timelines

Plans render scheduled activities against time: the plan view groups activities into swimlanes, gantt charts compose several plans, time strips stack any time-based views on one shared axis, and the time list shows the same activities as a sortable table. Activity category colors come from the chart palette slots; status colors appear only for execution problems.

Plan view#

A time-axis ruler on top, one swimlane per activity group. Bars are positioned by start/end on the shared scale; activities that overlap within a group stack onto separate rows (Suit telemetry watch below). The selected activity gets a primary outline with start/end drag handles — handles adjust times in edit mode only. The vertical ok-green line is current time.

Activity temporal & execution states#

Time classifies every activity as past, current, or future; execution monitoring adds overdue and aborted. Category color never changes with state — only opacity, fill, and a glyph. Critical red is reserved for execution problems.

Gantt chart — composed plans#

Time list#
