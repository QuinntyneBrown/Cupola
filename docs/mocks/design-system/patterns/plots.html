Plots & charts

Time plots are the workhorse telemetry view (OMCT-C07). One family covers single-series, overlay, and stacked plots plus bar and scatter forms — all on the void surface with hairline grids, a recessive axis, 11px mono ticks, and 2px series lines drawn from the fixed categorical slots --cp-chart-1…8. Every mock below is inline SVG standing in for the chart.js canvas the Angular implementation renders.

Single-series time plot — anatomy#

Toolbar (pan, zoom, reset, pause), y axis with engineering-unit label and mono ticks, x axis in UTC HH:mm, one 2px line in slot 1. A single series gets no legend box — the title names it. Hovering raises the crosshair hairline, an ≥8px marker, and a .cp-tooltip with mono values (OMCT-C07-L2-02.01…02.03).

Legend modes#

Any plot with ≥2 series always shows a legend; with ≤4 series the lines are also direct-labeled at their ends (see overlay). The legend has two modes (OMCT-C07-L2-02.04): collapsed — swatch, name, and latest value inline above the plot — and expanded — a table adding timestamp, min, max, and unit.

Limit lines & alarm points#

Limit lines and violating points wear status colors — never a series slot, and vice versa. Dashed horizontal lines mark each limit with a right-edge label; samples beyond a limit are re-marked with a triangle in the violated severity while the line itself keeps its series color (OMCT-C07-L2-02.07, OMCT-C06-L2-04.03).

Battery temp (°C) — tcs.batt2_t
Limits come from telemetry metadata or manual bounds. ▲ marks a high violation (▼ low); the triangles adopt the severity color while the line stays slot 1 — status hues never name a series.

Overlay plot — shared axis vs multi-axis#

An overlay plot draws several series in one coordinate space (OMCT-C07-L2-01.03). Series of the same unit share one y axis; series of different units switch to multi-axis mode where every axis is labeled by its series name with a swatch — two unrelated scales never share a plot unlabeled (OMCT-C07-L2-03.01).

Bus A 32.36 V Bus B 31.81 V Bus C 31.07 V
Shared-axis mode: three same-unit series, slots 1–3 assigned in order. ≤4 series are also direct-labeled at line ends — labels in ink, swatches carry the color.
Array output 3.46 kW Battery temp 23.94 °C
Multi-axis mode: units differ, so each series gets its own labeled axis — swatch + series name above the axis it owns. Gridlines bind to the left axis only. This is the only sanctioned multi-scale form; a dual-axis plot without per-series axis labels is forbidden.

Stacked plot — coordinated crosshair#

A stacked plot gives each series its own row and y axis while all rows share the x axis (OMCT-C07-L2-01.04, 03.02). Hover raises one crosshair through every row at the same timestamp, with a combined tooltip (OMCT-C07-L2-03.03).

Bar chart#

Bars are thin with a 2px surface gap between neighbors and a 4px rounded data-end — rounding only at the value end, square at the baseline. One series wears slot 1 alone. Values label the two most salient bars only, never every bar (OMCT-C07-L2-04.01).

PDU-2 outlet load (A)
Single series — the title names it, no legend box. Hover raises a per-bar tooltip. Spectral plots reuse this exact form with frequency bins on the x axis and amplitude on y (OMCT-C07-L2-04.02).

Scatter plot#

A scatter plot draws one point per sample from two range keys of the same telemetry stream — here pwr.array_out against pwr.bus_v. Both axes carry a name and unit (OMCT-C07-L2-04.03, 04.04).

Plot configuration inspector#

Plot options live in the inspector (OMCT-C07-L2-04.05). Browsing shows the same panel read-only (controls disabled); entering Edit — the violet mode — enables it. Series colors are constrained to the eight palette slots: no free color picking, and removing a series never re-colors the survivors.

Inspector — Plot configEditing
Palette slots only
Per-series required when units differ
Editing state shown (violet badge). Outside Edit mode the identical panel renders with disabled controls — configuration is inspectable but immutable.
Angular Inspector sections are mat-expansion-panel; controls bind a reactive form to the plot's configuration object. The swatch group is a custom control valued in slot indexes (1–8), not hex.

chart.js mapping#

Angular Every plot mock above renders as one chart.js canvas per plot (stacked = one canvas per row, x-linked). The base options are fixed by the design system: 
// plot-canvas.directive.ts — chart.js base options (design-system fixed)
new Chart(ctx, {
  type: 'line',
  data: { datasets },                 // dataset.borderColor = --cp-chart-N, assigned in slot order
  options: {
    animation: false,                // ops plots never animate data
    parsing: false,
    normalized: true,                 // pre-sorted {x,y} pairs from the telemetry adapter
    plugins: {
      decimation: { enabled: true, algorithm: 'min-max' },
      legend:  { display: false },    // legend is a Cupola component (OMCT-C07-L2-02.04)
      tooltip: { enabled: false }     // crosshair + .cp-tooltip overlay plugin instead
    },
    scales: {
      x: { type: 'time', time: { displayFormats: { minute: 'HH:mm' } },
           grid:   { color: '#232B3A' },              // --cp-chart-grid
           border: { color: '#384357' },              // --cp-chart-axis
           ticks:  { color: '#8290A9',                // --cp-chart-tick
                     font: { family: 'IBM Plex Mono', size: 11 } } },
      y: { title: { display: true, text: 'Bus voltage (V)' },
           grid: …, border: …, ticks: … }                // same chrome tokens
    },
    elements: {
      line:  { borderWidth: 2, tension: 0 },  // 2px marks, no smoothing
      point: { radius: 0, hoverRadius: 8 }    // markers appear on hover, ≥8px
    }
  }
});
