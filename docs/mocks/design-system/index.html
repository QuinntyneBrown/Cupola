Cupola · Mission operations frontend

Console-dark design system for flight operations

Cupola re-implements the Open MCT capability set on Angular. This design system defines every visual element the requirements in docs/specs call for — tokens, typography, spacing, and complete component mocks — in a single dark theme built for operators who watch telemetry for hours in dim rooms.

Principles#

  • Status colors are vocabulary, not decoration. Green, amber, and red are reserved for limit and health semantics. Editing is violet. Selection is cyan. A color is never the only signal — every state pairs with an icon, a label, or a type change.
  • Data wears mono. Every telemetry value, timestamp, and coordinate renders in IBM Plex Mono with tabular figures so columns of numbers hold still while they update.
  • Dense by default. Controls use Material density −2 (32px), telemetry rows are 24px. Operators scan walls of data; whitespace is spent between regions, not inside them.
  • Elevation is light, not shadow. Layers step from void to surface-3 by getting lighter; shadows appear only under detached layers (menus, dialogs, drag ghosts).
  • Motion is mechanical. 80–240ms, one standard easing, nothing bounces. prefers-reduced-motion zeroes transitions.

Requirement traceability#

Each component section lists the OMCT-Cxx-L2-nn.nn requirement identifiers it satisfies, drawn from the sixteen capability specs. Accessibility targets come from C16: WCAG 2 AA with zero axe violations, full keyboard operability, and no color-only state signaling. Text ink holds ≥4.5:1 against every surface; status hues hold ≥3:1 as fills and are always paired with a glyph or label.
