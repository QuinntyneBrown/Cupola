Mission operations frontend

Fly your mission from one console.

Cupola brings live telemetry, imagery, timelines, and operator notebooks into a single real-time console — browse the mission as a tree, compose it into dashboards, and watch it execute.

Open the app Explore the design system

MIT licensed · Angular 21 · ASP.NET Core 8 · SignalR

C09 · Layouts

Build the console your mission needs.

Compose telemetry, imagery, and widgets on a snap-to-grid canvas. Display layouts, flexible layouts, and tabs turn any object in the tree into an operator screen — saved and shared like any other object.

C07 · Plots

Plot anything the downlink sends.

Overlay, stacked, bar, and scatter plots with synchronized cursors, limit lines, and alarm markers. Every view follows the time conductor, so every plot answers the same question: what happened, when.

C11 · Imagery

Inspect every frame.

Scrub camera history on a filmstrip, zoom into the frame, and flip on reticle and horizon overlays. Brightness, contrast, a compass HUD, and in-image annotations — built for photo ops, not photo apps.

C12 · Planning

Plan the day. Watch it execute.

Activity plans render as Gantt charts, time strips, and time lists that share the mission clock — track execution against plan while telemetry and events scroll on the same axis.

C10 · Conditions

Know nominal from no-go.

Condition sets evaluate live telemetry into named states, and widgets restyle themselves the moment a limit trips. Derived telemetry computes what the spacecraft doesn't send.

C13 · Notebooks

The shift log, built in.

Capture entries with embedded snapshots of any view, tag them, and search them beside the objects they describe. Restricted notebooks keep flight logs append-only.

…and everything around them.

  • Time conductor

    One clock rules every view — fixed windows for analysis, real-time for ops.

  • Grand search

    Search objects and annotations from anywhere; jump straight to the result.

  • Tables, LAD & gauges

    Dense telemetry tables, latest-available-data views, meters, and autoflow.

  • Three themes

    Darkmatter for the console at night, Espresso for warmth, Snow for daylight.

  • Real-time sync

    Object edits and telemetry stream over SignalR to every open console.

  • Object tree

    Everything is an object with composition — folders, plots, plans, and cameras alike.

Open source

Built in the open.

Cupola is MIT-licensed and spec-driven: an Angular 21 frontend, an ASP.NET Core 8 backend, real-time SignalR — with every requirement traced to an acceptance test. The design system that styles it is documented and deployed on its own.
